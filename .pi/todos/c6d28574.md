Goal

Centralize high-confidence domain types in frontend/src/types so converted files can import shared interfaces and reduce duplication.

Work completed so far

1. Created new domain type files:
   - frontend/src/types/fido2.ts
     - exports Fido2Credential and GetUserFido2Response (conservative fields, TODO to tighten)
   - frontend/src/types/webauthn.ts
     - exports AttestationOptions, AssertionOptions, AttestationResult, AssertionResult (conservative)
   - frontend/src/types/hooks.ts
     - exports SubmitDataOptions and SubmitData used by useSubmit hook
2. Exported new types from frontend/src/types/index.ts
3. Updated code to consume the new types:
   - frontend/src/features/ManageFIDO2/utils/fetchUserFIDO2Credentials.ts now imports Fido2Credential and types setData accordingly
   - frontend/src/hooks/useSubmit.tsx now imports SubmitDataOptions and SubmitData from ../types/hooks

Why

- These changes validate that the shared type files are consumable by source modules without converting many files at once.
