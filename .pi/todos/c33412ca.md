Scope (Batch A)

Convert the following small, low-risk utilities to TypeScript (.js -> .ts or .jsx -> .tsx):

- src/utils/axiosInstance.js -> src/utils/axiosInstance.ts
- src/utils/apiErrorHandler.js -> src/utils/apiErrorHandler.ts
- src/utils/errorUtils.js -> src/utils/errorUtils.ts
- src/utils/faviconUtils.js -> src/utils/faviconUtils.ts
- src/utils/gatag.jsx -> src/utils/gatag.ts
- src/utils/routeHelpers.js -> src/utils/routeHelpers.ts
- src/utils/gcHelpCentreLinks.jsx -> src/utils/gcHelpCentreLinks.ts
- src/utils/userProfileDispatch.jsx -> src/utils/userProfileDispatch.ts

Steps

1. Create branch: feat/ts/batch-a-utils
2. For each file:
   - git mv to .ts/.tsx
   - add minimal types (function signatures, exported shape), prefer explicit interfaces
   - add // TODO comments where types can be narrowed later
3. Update imports across the repo to remove explicit .js/.jsx extensions (run codemod or manual)
4. Run build check locally:
   - npm --prefix frontend ci
   - npm --prefix frontend run build
5. Fix TS errors with minimal any if necessary, add TODO to tighten types.
6. Open PR with description of changed files and remaining TODOs.

Acceptance criteria

- npm --prefix frontend run build completes successfully on the branch
- No runtime behavior changed (smoke-tested)
- PR contains a short TODO list of follow-up type improvements

Estimated effort: 1–2 days
