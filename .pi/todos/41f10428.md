Scope (Batch F)

Convert Storybook stories and unit tests to TypeScript if desired. These are large files and usually lower priority; convert only where it improves developer DX.

Steps

1. Create separate PRs for story files grouped by feature (e.g., MFAPhoneNumber stories, EmailAddress stories)

3. Run: npm --prefix frontend run test and storybook build

- Storybook build works and selected unit tests pass
