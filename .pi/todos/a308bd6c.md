Objective

Add a GitHub Actions workflow to run type checking and build verification for PRs. Start non-blocking (report-only) and make blocking after migration stabilizes.

Implementation

1. Create .github/workflows/ci-types.yml with job:
   - checkout
   - setup-node (use Node 20+)
   - npm ci
   - npm run typecheck (tsc --noEmit)
   - npm run build (optional heavy; can be gated behind a label)
2. Configure the job to run on pull_request and push to main
3. Make job non-blocking initially; capture artifacts/logs

Acceptance criteria

- Workflow exists and runs for PRs; TypeScript errors are reported but do not block merges initially
- After sufficient conversion, change workflow to be required in branch protection

Notes

- Use separate job for build if runtime cost is high; keep typecheck fast.
