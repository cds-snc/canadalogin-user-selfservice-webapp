Objective

Create a safe codemod that rewrites import and require specifiers ending in .js or .jsx to extensionless imports (so renamed .ts/.tsx files resolve correctly).

Implementation plan

1. Add a transform script at frontend/scripts/transform-remove-js-ext.cjs using jscodeshift or ts-morph.
2. Provide a dry-run mode that prints proposed changes without applying.
3. Add usage instructions and a git pre-check to ensure working tree is clean.
4. Test the codemod against a small fileset (Batch A sample) and commit changes in a branch.

Acceptance criteria

- Script exists at frontend/scripts/transform-remove-js-ext.cjs
- Running the script in dry-run shows expected replacements for sample imports
- Script can be run with: node scripts/transform-remove-js-ext.cjs --apply --path src (or via npx jscodeshift -t scripts/transform-remove-js-ext.cjs src)

Notes

- Do NOT run the script automatically across the repo; use it per-PR to update imports after renaming files.
