Goal

Create a reproducible way to extract declaration (.d.ts) files from existing JS/TS source to get a baseline of available types. This helps during migration by providing module shapes and surface area.

What I added

- frontend/tsconfig.extract.json — extends existing tsconfig.app.json and sets allowJs + declaration + emitDeclarationOnly with outDir=./types-extracted

How to run

1. From frontend/ run:
   - npx tsc -p tsconfig.extract.json

2. Output will be written to frontend/types-extracted/ as .d.ts files.

Notes

- The generated declarations will be conservative (many `any`), but provide a module map and exported names which is useful for deciding conversion priority.
- This step is non-destructive and safe to run repeatedly.
