# Bruno API Collection

This folder contains API collection files for [Bruno](https://www.usebruno.com/), an open-source alternative to Postman.

## About Bruno

Bruno is a fast and Git-friendly API client that stores collections directly in your filesystem.

## Collection Files

- `Bruno-IBM Security Verify API.json` - IBM Security Verify API collection for testing and development

## Getting Started

1. Download and install Bruno from [https://www.usebruno.com/](https://www.usebruno.com/)
2. Open Bruno and import the collection file
3. Configure any required environment variables or authentication settings
4. Start making API requests

## Benefits of Bruno

- **Git-friendly**: Collections are stored as plain text files
- **Open-source**: Free and community-driven
- **Fast and lightweight**: No unnecessary bloat
- **Privacy-focused**: Works offline, no cloud sync required
- **Collaboration-friendly**: Easy to share and version control with your team
